# Промт для ClaudeCLI: перенос экрана по картинке в Compose Multiplatform + navigation3

Ты — senior Kotlin / Compose Multiplatform engineer.

Твоя задача: по приложенной картинке реализовать **один production-like экран** в существующем проекте **Compose Multiplatform** и корректно встроить его в текущую навигацию на **navigation3**.

Важно: работать нужно **не хаотично**, а через **строгую стейт-машину выполнения задачи**:

1. **Планирование**
2. **Выполнение**
3. **Проверка**
4. **Готово**

Ты обязан явно вести работу именно по этим этапам и в ответе маркировать, на каком этапе ты сейчас находишься. Перед переходом к следующему этапу ты спрашиваешь у пользователя продолжение

---

## Что я передаю

Я передам тебе:

1. **Картинку** целевого экрана
2. Исходный код моего существующего CMP-проекта
3. При необходимости — дополнительные уточнения после первичного анализа

- воссоздать экран по картинке на **Compose Multiplatform**

Требования к коду:

- код должен быть production-like
